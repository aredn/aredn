# Current HUB-5 UI — November 25, 2026

These are screenshots of fresh authenticated native HTTP and served CSS captured
from HUB-5 running AREDN 4.26.10.0 at 18:11 UTC, rendered in a fully intercepted
offline browser replay. They are **not direct live-browser captures or simulated
receiver states**. The browser policy blocked navigation to the local SSH tunnel.

All twelve installed GUI/native-source hashes matched GUI revision
`aa9e2b8fa1f69b3c6c05620cb2d082c5b74b8114`. The receiver reported GPS locked at
capture time. No application/native-synchronization code or node settings were
changed for this screenshot update.

- [Compact status](hub5-status-20261125.png): uppercase PST with the normal
  clock style; source/receiver information is in the hover rather than a
  standalone status-page detail line.
- [Time popup](hub5-time-popup-20261125.png): the currently installed **three-column
  desktop** details section at the bottom of the existing settings popup.

The latest reviewer comment prefers the two-column comparison. That preference
is recorded but is **not implemented by this documentation-only snapshot**.
Badge wording, colored text versus bubbles, and whether to show unknown status
also remain open design questions. Existing controlled comparison screenshots
are retained separately.
